# CodePawl × Orynt Brand Kit

## Brand relationship

- **CodePawl** — company brand; mark is the hand-drawn code motif `>.-`.
- **Orynt** — CodePawl product; mark is the hand-drawn five-ray lightbulb.

## Visual direction

- Primary ink: `#241F1A`
- Warm canvas: `#F7F3ED`
- Style: hand-drawn illustration with rounded, slightly irregular strokes.

## Files

Each brand directory contains:

- `<brand>-mark.png` / `.svg` — square transparent mark, safe for circular avatar crop.
- `<brand>-lockup.png` / `.svg` — transparent horizontal mark + wordmark.
- `<brand>-banner.png` — `1500 × 500` warm-canvas social banner.

The editable source for both brands is `codepawl-orynt-brand-kit.tldraw`.

Use `codepawl-orynt-brand-kit-preview.png` for a quick overview. The small-size and circular-crop sheets are QA references, not production assets.
