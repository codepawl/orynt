# Code of Conduct

Be kind. Be clear. Talk about the work, not the person.

## Good behavior

- Give useful feedback.
- Ask questions before making assumptions.
- Welcome people with less experience.
- Respect privacy.
- Accept maintainer choices about safety and project scope.

## Bad behavior

- Harassment or threats
- Personal attacks
- Discrimination
- Sexual comments or unwanted attention
- Sharing private information
- Trolling or trying to stop useful discussion
- Pushing people to test systems without permission
- Punishing someone for making a good faith report

## Where this applies

These rules apply in Orynt issues, pull requests, reviews, discussions, and
other spaces used for Orynt work.

They also apply when someone speaks for the project.

## Report a problem

Use GitHub reporting tools for public content.

For a private concern, use the contact path on the CodePawl GitHub profile. Do
not open a public issue with private evidence.

Use private vulnerability reporting only when the report also contains a
security problem.

Maintainers may remove content, close a thread, reject a change, warn someone,
or block someone from the project.
