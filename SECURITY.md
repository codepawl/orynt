# Security

## Supported version

Only the newest `0.1.x` release gets security fixes.

## Report a problem

Do not open a public issue.

Use GitHub private vulnerability reporting for this repo.

Include:

- The Orynt version
- What part is affected
- Steps that show the problem
- What an attacker could do
- Safe evidence that helps us test the report

Do not send real passwords, tokens, cookies, private keys, or private code.

If private reporting is not available, use the contact path on the CodePawl
GitHub profile. Share only enough information to open a private conversation.

## Rules for security testing

- Test only systems you own or have permission to test.
- Use fake accounts and fake data when possible.
- Do not read, change, save, or share other people's data.
- Do not run denial of service tests.
- Do not use social engineering or credential attacks.
- Stop when a test could cross a privacy or permission limit.

We will not treat good faith testing that follows these rules as an attack on
the project.

## What maintainers will do

Maintainers will test the report in a safe setup. We will check which releases
are affected. We will publish a fix and a GitHub advisory when needed.

If a release key or npm token may be exposed, we will replace it.
