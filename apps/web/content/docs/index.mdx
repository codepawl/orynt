## What is CodePawl?

CodePawl is an open-source AI/ML community platform built for researchers, engineers, and enthusiasts. It combines a technical blog, discussion forum, paper reproduction tracker, and open-source project showcase into a single space.

**Live at:** [codepawl.com](https://codepawl.com)

## Platform Features

### Blog

A community-driven technical blog where members publish articles on AI/ML topics. Posts are written with a rich text editor (Tiptap), support cover images, tags, and reading time estimates. Published posts are automatically shared to the community forum.

[Read the Blog guide &rarr;](/docs/community)

### Community Forum

A Hacker News-style discussion forum with ranked and chronological feeds, threaded comments, upvoting, and a karma system. Supports three post types: links, text discussions, and Show CodePawl project showcases.

[Read the Community guide &rarr;](/docs/community)

### Papers

A paper reproduction and verification hub. Submit papers from arXiv, write reproduction reports documenting your results, and track verification status across the community.

[Read the Papers guide &rarr;](/docs/papers)

### Projects

An open-source project showcase that syncs with the [codepawl GitHub org](https://github.com/codepawl). Projects display live stats (stars, forks, language, latest release) and have dedicated hub pages with README parsing, wiki documentation, and community discussions.

[Read the Projects guide &rarr;](/docs/projects)

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 16 (App Router), React 19, TypeScript |
| Styling | Tailwind CSS + Ant Design 6, dark/light mode via next-themes |
| Backend | FastAPI (Python 3.12), async |
| Database | Supabase (PostgreSQL) with Row Level Security |
| Auth | Supabase Auth (GitHub OAuth + email/password) |
| Monorepo | Bun workspaces |
| Monitoring | Sentry (client, server, edge) |
| Deployment | Vercel (frontend) + Koyeb (backend) |

## Monorepo Structure

```
codepawl/
├── apps/
│   ├── web/          # Next.js frontend (@codepawl/web)
│   └── api/          # Python FastAPI backend
├── packages/
│   └── shared/       # @codepawl/shared (types, constants, config)
├── ROADMAP.md        # Development roadmap
└── package.json      # Bun workspaces root
```

## Getting Started

```bash
# Clone and install
git clone https://github.com/codepawl/codepawl.git
cd codepawl
bun install

# Start the frontend dev server
bun run dev

# Start the backend (requires Python 3.12 + venv)
bun run dev:api

# Or start both at once
./dev.sh
```

## Shared Package

The `@codepawl/shared` package provides TypeScript types, constants, and utilities shared between the frontend and backend. See the [shared package reference](/docs/shared) for full API documentation.
