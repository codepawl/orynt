## Overview

`@codepawl/shared` is the shared TypeScript package used across the CodePawl monorepo. It provides type definitions that mirror FastAPI response shapes, shared constants, and a utility for resolving the backend API URL.

## Installation

The package is a Bun workspace dependency. It's already available in `apps/web`:

```json
{
  "dependencies": {
    "@codepawl/shared": "workspace:*"
  }
}
```

Import from anywhere in the frontend:

```typescript
import { CATEGORIES, KARMA_THRESHOLDS, getBackendApiUrl } from "@codepawl/shared";
import type { Profile, CommunityPost, BlogPost } from "@codepawl/shared";
```

## Utilities

### `getBackendApiUrl()`

Returns the backend API URL based on the current environment:

```typescript
function getBackendApiUrl(): string
```

**Resolution order:**

1. `process.env.BACKEND_API_URL` (server-side, not exposed to client)
2. `process.env.NEXT_PUBLIC_BACKEND_API_URL` (client-side)
3. `"http://localhost:8000"` (fallback)

### `CATEGORIES`

The 15 AI/ML topic categories used for tagging posts, papers, and challenges:

```typescript
const CATEGORIES = [
  "general", "llm", "computer-vision", "nlp", "rag",
  "mlops", "agents", "training", "open-source", "research",
  "hardware", "safety", "multimodal", "data", "robotics",
] as const;

type Category = (typeof CATEGORIES)[number];
```
