## Overview

The Challenges Hub aggregates AI/ML competitions from platforms like Kaggle, DrivenData, Zindi, and AIcrowd into a single feed. Browse active competitions, bookmark ones you're interested in, and find teammates from the CodePawl community.

## Features

### Competition Aggregation

Challenges are collected from multiple platforms and displayed in a unified feed. Each listing includes:

- **Title** and description
- **Platform** source (Kaggle, DrivenData, etc.)
- **Prize** amount and type
- **Deadline** with countdown
- **Tags** matching CodePawl's AI/ML categories
- **Difficulty** level estimate
- **Team size** requirements

### Bookmarks

Save competitions you want to track. Bookmarked challenges appear in your profile and send reminders as deadlines approach.

### Team Requests

Looking for teammates? Post a team request on any challenge:

- Describe the skills you're looking for
- Set your target team size
- Link to your existing work or approach
- Community members can apply to join

## Categories

Challenges are tagged using the same 15 categories as the rest of the platform:

```typescript
const CATEGORIES = [

  "mlops", "agents", "training", "open-source", "research",
  "hardware", "safety", "multimodal", "data", "robotics",

```

Filter by category to find competitions matching your expertise.
