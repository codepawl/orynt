## Overview

The Papers section is a community-driven hub for tracking and reproducing AI/ML research. Submit papers from arXiv, write detailed reproduction reports, and help the community verify claims with real experiments.

## Verification Status

Each paper has a verification status that reflects the community's collective reproduction efforts:

| Status | Meaning |
|--------|---------|
| **Unverified** | No reproduction attempts yet |
| **Verified** | At least one reproduction confirms the paper's claims |
| **Partially Reproduced** | Some claims confirmed, others not |
| **Disputed** | Reproduction attempts contradict the paper's claims |

```typescript
type VerificationStatus =
  | "unverified"
  | "verified"
  | "partially_reproduced"
  | "disputed";
```

## Submitting a Paper

1. Navigate to [/papers/submit](/papers/submit)
2. Paste an arXiv URL — metadata (title, authors, abstract, year) is auto-extracted
3. Optionally add a direct PDF link
4. Add tags from the available categories
5. Submit for community review

The arXiv metadata extraction parses the paper's title, author list, abstract, and publication year automatically.

## Writing a Reproduction Report

A reproduction report documents your attempt to replicate a paper's results. Each report includes:

### Required Fields

- **Result**: One of `confirmed`, `partially`, `failed`, or `different_findings`
- **Summary**: A concise description of your reproduction attempt and findings

### Optional Fields

- **Hardware**: What hardware you used (e.g., "4x A100 80GB", "M2 MacBook Pro")
- **Framework**: Software framework (e.g., "PyTorch 2.1", "JAX 0.4.20")
- **Model Tested**: Specific model variant or checkpoint
- **Code URL**: Link to your reproduction code repository
- **Paper Claims**: Structured list of claims from the original paper
- **Actual Results**: Your measured results corresponding to each claim
- **Details**: Extended writeup with methodology, challenges, and observations

### Reproduction Results

```typescript
type ReproductionResult =
  | "confirmed"       // Results match paper claims
  | "partially"       // Some claims confirmed, others not
  | "failed"          // Could not reproduce results
  | "different_findings"; // Found different but notable results
```

## Paper Data Model

```typescript
interface Paper {
  id: string;
  title: string;
  authors: string;
  arxiv_url: string | null;
  pdf_url: string | null;
  venue: string | null;
  year: number | null;
  abstract: string | null;
  tags: string;
  submitted_by: AuthorInfo | null;
  verification_status: VerificationStatus;
  reproduction_count: number;
  created_at: string;
  updated_at: string;
}
```

## API Reference

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/papers/` | GET | List papers (paginated) |
| `/api/papers/` | POST | Submit a paper (auth required) |
| `/api/papers/{id}` | GET | Get paper detail with reproductions |
| `/api/papers/{id}/reproductions` | GET | List reproduction reports |
| `/api/papers/{id}/reproductions` | POST | Submit a reproduction (auth required) |
| `/api/papers/arxiv-metadata` | GET | Extract metadata from arXiv URL |
