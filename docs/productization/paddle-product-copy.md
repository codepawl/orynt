# Paddle Product Copy

Launch status: private beta draft, not live Paddle configuration.

## Product Positioning

CodePawl is a supervised desktop control plane for computer-use agents. The beta focuses on local repository workflows, visible permission gates, audit evidence, usage limits, and user takeover for sensitive work.

Do not describe CodePawl Gateway as a payment gateway, marketplace, escrow service, checkout provider, or autonomous purchasing system. Gateway means the permission and evidence layer that routes computer-use actions.

## Plans

### Core BYOK

Paddle product name: CodePawl Core BYOK

Short description: Local supervised agent workflows for users who connect their own model provider keys.

Included:
- Desktop app access during private beta.
- Repository-scoped Coding Apprentice workflow.
- Local run timeline, approvals, artifacts, memory review, and skill review.
- Bring-your-own-key model usage. Managed AI credits are not included.

### Managed AI

Paddle product name: CodePawl Managed AI

Short description: CodePawl with included managed AI credits and the same local permission controls.

Included:
- Everything in Core BYOK.
- Monthly managed AI credits that reset every month.
- Managed provider routing for supported beta workflows.
- Usage and quota display for runs, credits, and gateway actions.

### Pro/Gateway

Paddle product name: CodePawl Pro Gateway

Short description: Higher supervised action quotas and audit controls for operators testing broader computer-use workflows.

Included:
- Everything in Managed AI.
- Higher monthly managed AI credits.
- Higher gateway action quota.
- Expanded audit evidence and policy review features as they become available.

## Billing Rules

- Monthly managed AI credits reset monthly, including quarterly or annual billing experiments.
- BYOK usage and managed AI usage must remain separate in copy, UI, and accounting.
- No production Paddle secrets, product IDs, prices, or webhooks are stored in this repository.
- Private beta prices are placeholders until Paddle review and operator approval.
