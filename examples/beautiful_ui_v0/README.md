# beautiful_ui_v0

Self-authored positive UI corpus for future Pawl-JEPA representation pretraining experiments.

- 40 standalone static HTML/CSS examples.
- No external URLs, scripts, CDNs, fonts, images, screenshots, logos, or brand assets.
- Fictional product names and copy only.
- Designed for 1440x900 local rendering with accessible contrast, clear hierarchy, and varied layouts.

Build:

```bash
uv run pawlbench-design-positive-build examples/beautiful_ui_v0 --out artifacts/datasets/beautiful_ui_v0 --seed 42
```
