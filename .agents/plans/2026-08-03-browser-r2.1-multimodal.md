# Browser R2.1 multimodal implementation

Status: implemented foundation; provider-live validation remains consent-gated.

Scope:

- verified local image inputs for Responses API and Codex app-server;
- app-server capability discovery and image-generation result capture;
- revision-bound browser candidate crops, limited to three and blocked for
  credential, OTP, and payment targets;
- one in-memory browser-vision trust grant bound to repository realpath,
  provider, model, and exact origins;
- explicit raster asset requests, maximum four outputs, exact writer paths,
  atomic writes, and mandatory `assets/PROVENANCE.md` records.

Non-goals:

- general desktop computer use;
- implicit image generation;
- SVG generation through an image model;
- third-party vision providers;
- live provider/quota benchmarks without separate operator consent.

Remaining promotion evidence:

- a consented live Responses image-input/image-generation canary;
- a consented live Codex app-server image-input/image-generation canary;
- end-to-end CLI browser crop handoff evaluation on the private canary suite.
