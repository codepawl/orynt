# Trial, pricing, packaging

These are product hypotheses for MVP validation. Do not hard-code final prices without founder approval.

## Packaging decision

CodePawl is closed-source commercial software.

Recommended early distribution:

- Desktop app download.
- Offline-first local alpha with placeholder trial state.
- Account-gated trial can be added after runtime value is proven.
- BYOK model provider support from day one.
- Optional included credits later.
- No public self-hosted open-source edition in MVP.

## Trial options

Preferred trial:

```text
14 days
50 controlled browser runs
100 saved traces
3 saved skills
BYOK required OR small included trial credits
```

Alternative trial:

```text
7 days
unlimited local UI usage
20 agent executions
```

## Plan hypotheses

### Free Trial

- Limited runs.
- Browser surface only.
- Basic permission presets.
- Usage dashboard.
- Local traces.

### Starter

- For solo operators.
- Browser surface.
- Saved skills.
- More traces.
- BYOK.
- Budget caps and alerts.

### Pro

- Advanced token optimization.
- Weak-model routing.
- More saved skills.
- Exportable run reports.
- Priority local features.

### Team later

- Shared workspaces.
- Shared skills.
- Policy templates.
- Audit logs.
- Central billing.

## Pricing display principles

- Keep pricing page simple: 3 plan cards maximum.
- Show that model/API spend is separate unless included credits exist.
- Position token economy as value: “avoid runaway agent bills.”
- Trial CTA should be visible in top bar and onboarding.
- Make it clear that alpha billing/account actions are placeholders until the commercial backend exists.
