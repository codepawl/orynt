# Customer journey

## First session

1. Install CodePawl.
2. Create account / start trial.
3. Choose model provider or trial credits.
4. Choose permission preset.
5. Start first task from a suggested card.
6. Watch live browser and agent log.
7. Approve one risky step.
8. See success + cost summary.
9. Save successful run as skill.

## First paid conversion trigger

The user should see one of these outcomes:

- “This saved me setup time.”
- “This is less scary than letting an agent run blindly.”
- “I can see why it failed.”
- “The run would have been expensive, but CodePawl stopped it.”
- “I can replay this next time without paying for full reasoning again.”

## Retention loop

- Re-run saved skill.
- Review failed task.
- Lower cost with model routing.
- Add domain-specific permission rule.
- Schedule or manually trigger recurring workflow later.
