# CodePawl CLDSA-Lite Plan

This folder is the current P0 planning source for CodePawl.

CLDSA-Lite supersedes the earlier browser-first MVP plan. The first sellable
capability is a supervised Coding Apprentice that delegates repository tasks to
Codex inside an isolated git worktree, verifies outcomes deterministically,
records append-only run evidence, controls cost, and converts user corrections
into candidate memory and skills.

Browser automation remains part of the long-term capability-pack architecture,
but it is not the first executable P0 slice.
