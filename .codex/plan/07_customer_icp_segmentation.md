# Customer, ICP, and Segmentation

Generated: 2026-06-24

## Initial ICP

Technical solo users and small teams who already use AI coding/agent tools and feel the pain of brittle browser/computer automation.

## Segment A: AI engineers and automation builders

Pain:

- Agents burn tokens.
- Computer-use demos are hard to reproduce.
- Terminal-first tools are not pleasant for daily operation.
- Failures are hard to debug.

Value proposition:

- Inspectable traces.
- Context/cost controls.
- Weak-model support.
- Reusable skills.

## Segment B: QA engineers and developers

Pain:

- Manual regression testing is repetitive.
- Playwright tests require maintenance.
- AI agent runs are black-box and unreliable.

Value proposition:

- Agent-generated exploratory flows.
- Console/network capture.
- Replayable traces.
- Exported bug reports.

## Segment C: Data operators / analysts

Pain:

- Important data exists behind logged-in dashboards with no API.
- Manual extraction is tedious.
- RPA tools are overkill.

Value proposition:

- Browser workflow extraction.
- Approval gates.
- CSV/JSON export.

## Segment D: Indie hackers / solopreneurs

Pain:

- Need automation but do not want enterprise RPA.
- Need to automate tools they already use.

Value proposition:

- Beautiful cockpit.
- Fast setup.
- Local-first.
- Pay-as-needed model adapter.

## Avoid early

- Large regulated enterprises.
- Payment-heavy workflows.
- Medical/legal autonomous workflows.
- Non-technical consumers expecting magic full-computer autonomy.
