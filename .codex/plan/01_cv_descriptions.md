CodePawl explores the control layer missing from today’s computer-use agents: semantic UI observation, deterministic action compilation, token-aware context routing, human approval gates, trace replay, and skill compilation. The MVP starts with browser automation, but the architecture is built around pluggable Surface Adapters for future desktop, file-system, terminal, and cross-app workflows.
