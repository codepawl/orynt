## Demo script

1. Open CodePawl.
2. Launch browser.
3. Open local form fixture.
4. Ask agent to fill form from JSON.
5. Show semantic UI graph.
6. Show action ledger.
7. Show token HUD.
8. Pause before submit.
9. Save skill.
10. Replay skill cheaper.
