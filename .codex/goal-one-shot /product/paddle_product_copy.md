## What will you be selling on Paddle?

Software subscriptions for CodePawl, a computer-use agent product that helps users teach, customize, and supervise AI agents to perform computer-based tasks according to their workflow and preferences.

CodePawl includes an agent cockpit for starting tasks, monitoring actions, approving sensitive steps, reviewing execution history, saving reusable workflows, and improving future behavior through feedback. The product is inspired by cognitive principles such as memory, planning, attention, feedback, and iterative learning.

We may also sell optional software add-ons such as CodePawl Gateway, a secure connector module that helps route agent tasks, integrations, and local/cloud workflow communication. These add-ons are part of the CodePawl software platform. We do not sell physical goods, marketplaces, payment processing services, or standalone human consulting services.

## Brief description of your product(s)

CodePawl is a computer-use agent software platform. It lets users customize and supervise AI agents that can perform computer-based tasks, while giving users control over permissions, task history, feedback, reusable workflows, and sensitive actions.

The platform may include optional software modules such as CodePawl Gateway, a secure connector for agent task routing, integrations, and local/cloud workflow communication. CodePawl is sold as software subscriptions and software add-ons only.
