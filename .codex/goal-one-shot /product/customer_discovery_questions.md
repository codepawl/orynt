# Customer Discovery Questions

## Workflow pain

1. What repetitive computer task wastes the most time every week?
2. Which task requires enough judgment that normal automation fails?
3. Which browser or desktop workflows do you repeat across tools?
4. What do you currently use: ChatGPT, Claude, Cursor, RPA, Zapier, scripts, assistants, VA, or nothing?
5. What is still manual after using those tools?

## Trust and safety

6. What actions would you allow an agent to do automatically?
7. What actions require approval?
8. What actions should always be blocked?
9. What evidence would you need after an agent completes a task?
10. Would you let the agent access local files? Under what constraints?

## Memory and teaching

11. What preferences do you repeat to AI tools?
12. What workflow would you want the agent to remember forever?
13. What should the agent forget after a task?
14. Would you approve/edit saved skills?
15. How would you know the agent learned correctly?

## Pricing

16. Would you prefer BYOK or managed AI usage?
17. Would you pay monthly, quarterly, or annual?
18. What price is acceptable if CodePawl reliably handles one painful workflow?
19. What usage limit would feel fair?
20. What would make you cancel after the first month?

## Purchase trigger

21. What urgent task would make you install CodePawl today?
22. What integration is mandatory?
23. What would make CodePawl different from Operator, Claude Code, Manus, Devin, or browser agents?
