## Core sections

### 1. Teach once, reuse often

Turn repeated tasks into approved skills. CodePawl remembers your preferred formats, tools, sites, and review rules.

### 2. Supervised autonomy

The agent can browse, draft, organize, and operate through a controlled gateway. Sensitive actions require approval or takeover.

### 3. Memory that you control

CodePawl separates short-term task state, long-term preferences, previous episodes, and reusable skills. You can inspect, edit, or delete durable memory.

### 4. Evidence for every action

Review screenshots, logs, diffs, permission decisions, and task summaries. See what happened before trusting the result.

### 5. Built for real workflows

Use CodePawl for research, repetitive browser tasks, local workflow automation, file organization, technical operations, and recurring SOPs.
