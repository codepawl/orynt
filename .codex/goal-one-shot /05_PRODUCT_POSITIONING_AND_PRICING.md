# Product Positioning and Pricing

## Positioning

Primary positioning:

> CodePawl is a teachable computer-use agent cockpit. It learns how you work, performs computer tasks under your supervision, remembers reusable workflows, and asks before sensitive actions.

Short version:

> Teach your AI agent how to use your computer safely.

## Why this matters now

Current AI agents are becoming capable of browser, terminal, and app actions, but users still hesitate because of:

- lack of trust;
- hidden reasoning and weak auditability;
- poor memory of user-specific workflow;
- unclear permission boundaries;
- fear of mistakes in email, payments, files, and production systems;
- unpredictable cost;
- lack of repeatable skill extraction.

CodePawl should sell trust, control, and compounding workflow memory.

## Urgent customer segments

### Segment 1 — Solo founders and technical operators

Problems:
- too many repetitive admin/browser tasks;
- research, lead lists, support replies, invoices, CRM updates;
- need automation but cannot build every integration.

Message:
- "Delegate repetitive computer tasks without losing control."

### Segment 2 — AI engineers and developers

Problems:
- many tools, terminals, dashboards, docs, issue trackers;
- need agent help but want local control and clear approvals;
- already comfortable with BYOK and custom workflows.

Message:
- "A controllable computer-use cockpit for serious AI workflows."

### Segment 3 — Agencies and small teams

Problems:
- repeated client workflows;
- need SOPs and replayable evidence;
- need junior-operator automation without hiring.

Message:
- "Turn repeated work into supervised AI skills."

### Segment 4 — Power users with privacy concerns

Problems:
- generic cloud agents do not fit personal environment;
- users want local gateway, selective memory, and permission control.

Message:
- "Your agent learns your workflow, not everyone else's."

## Differentiators

| Competitor type | Their strength | CodePawl wedge |
|---|---|---|
| General browser agents | Can operate websites | CodePawl emphasizes teachable memory, permissions, and replay |
| Coding agents | Deep codebase tools | CodePawl is broader computer-use, not coding-only |
| Automation tools | Deterministic and reliable | CodePawl handles ambiguous tasks and learns from feedback |
| RPA platforms | Enterprise process automation | CodePawl is personal/team-first and easier to teach |
| Chatbots | Easy interface | CodePawl acts through controlled gateway with evidence |

## Packaging

Start with two modes.

### Core BYOK

For users with their own model keys.

Suggested:
- $19/month
- $49/quarter
- $179/year

Includes:
- local/controlled gateway;
- task cockpit;
- memory;
- skill library;
- basic replay;
- bring-your-own API key.

Why:
- Lower COGS.
- Good for technical early adopters.
- Easier to launch before exact model cost is known.

### Managed AI

For users who want CodePawl to manage models.

Suggested:
- $49/month
- $129/quarter
- $469/year

Includes:
- managed model credits;
- memory and skills;
- gateway usage;
- replay;
- priority model routing.

Rules:
- Credits reset monthly even if billing is quarterly/annual.
- Heavy model usage consumes more credits.
- Overage should be top-up or plan upgrade.

### Pro / Gateway

For heavy users and small teams.

Suggested:
- $99/month or $149/month.
- Quarterly: $249–$399 depending quota.
- Annual: $949+.

Includes:
- more workspaces;
- more gateway volume;
- longer history;
- more approved skills;
- advanced connectors;
- team seats.

## Quarterly plan logic

Quarterly is reasonable because CodePawl needs time to learn workflows. It should not be the default hero plan.

Recommended pricing:
- Monthly: baseline.
- Quarterly: 10–15% discount.
- Annual: 20–25% discount.

Monthly credits should still reset monthly.
